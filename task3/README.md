## Техническая информация по проекту

### 1. Используемая модель

Для векторизации используется модель:

**sentence-transformers/all-MiniLM-L6-v2**

Метрика сходства: cosine similarity  
Индекс: FAISS (IndexFlatIP с нормализованными embedding)

---

### 2. База знаний

Синтетическая база знаний о вымышленной строительной компании **NordBuild Dynamics (NBD)**.

- 30 отдельных документов
- 6 доменных блоков (Corporate, Finance, Projects, Compliance, Operations, HR)
- Каждый файл имеет строгую структуру
- В каждом документе есть уникальный CANARY-маркер

База полностью автономна и не использует реальные данные.

---

### 3. Количество чанков в индексе

Документы разбиты на чанки фиксированного размера.

Общее количество чанков в FAISS-индексе:  
**30**

---

### 4. Время генерации

- Генерация базы знаний: ~60 минут  
- Построение индекса и embedding: ~1–3 минуты  

Проект полностью воспроизводим.
