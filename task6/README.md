# Автоматическое обновление векторной базы (update_faiss.py)

## Что делает скрипт update_faiss.py

Скрипт выполняет инкрементальное обновление FAISS-индекса.

Основная логика:

1. Сканирует папку `DATA_DIR` и находит все `.txt` файлы.
2. Для каждого файла вычисляет SHA256-хэш (fingerprint).
3. Сравнивает хэш с данными в `index_state.json`.
4. Если файл новый или изменён:
   - Делит его на чанки
   - Генерирует embedding для новых чанков
   - Добавляет векторы в `nbd.index`
   - Добавляет метаданные в `nbd_meta.jsonl`
5. Обновляет `index_state.json`.

Если изменений нет — индекс не модифицируется.

При первом запуске:
- Если `nbd.index` и `nbd_meta.jsonl` уже существуют,
- Скрипт создаёт `index_state.json` (режим bootstrap),
- Новые векторы не добавляются.

---

## Ручной запуск

```bash
python3 update_faiss.py
```

## Автоматический запуск каждый день в 22:00 (cron)

Открыть crontab:
```bash
crontab -e
```

Добавить строку:
```bash
0 22 * * * cd /ABSOLUTE/PATH/TO/PROJECT && /usr/bin/python3 update_faiss.py >> update_faiss.log 2>&1
```

Скрипт будет автоматически запускаться ежедневно в 22:00.
Обновление выполняется инкрементально и не требует полной пересборки индекса при отсутствии изменений.
